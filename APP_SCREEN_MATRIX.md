# APP_SCREEN_MATRIX — LensMate phone app

Source of truth for screens: `apps/mobile/app/*.tsx` (Expo Router). Goal section 5.1 groups are used in the Group column.
Evidence levels (Goal section 1.3): **Unit** = Jest test; **Browser** = Expo web build in a browser against the dev
broker (mock or live); **Simulator** = virtual glasses; **Emulator / Real phone / Hardware** = not yet run.

Phase column follows LensMate-Goal.md section 2 and 8. A screen built outside the current authorization is marked
**Built ahead of phase**: it exists in the app but is not evidence of current-phase delivery. Nothing here is a
claim of device readiness.

## Summary

- 12 routes and 1 global shell. Current-phase functional evidence: Browser and Unit for the P-1 screens listed above.
- Built ahead of phase: `/tasks`, `/interview`. Both are switched off by default in Profile → Features and show a
  notice instead of their controls; the home tiles and profile buttons are hidden or disabled while off. Not counted as
  current-phase work.
- No screen has device evidence (emulator, Android phone, iPhone). Native behaviour is not claimed for any screen.
