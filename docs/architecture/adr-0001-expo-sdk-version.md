# ADR-0001: Expo SDK version

Status: accepted (engineering decision by the agent, within the owner's approval record)
Date: 2026-10-20
Requirement: Engineering Standards 1 (stack), Goal section 10A, decision G46

## Context

G46 approves an Expo cross-platform app (iOS and Android) with development builds, never Expo Go. The Standards require the Expo SDK to be pinned and upgraded at most once per SDK release, through `npx expo install --fix` and the full test suite.

## Options considered

1. Latest stable Expo SDK line at the time of this decision.
2. The previous SDK line, for a longer patch history.
3. A prerelease line.

## Choice

Option 1: pin the latest stable Expo SDK line, `expo@58.0.16` (latest published stable version on npm when this ADR was written; 58.0.15 and 58.0.16 were published on 2026-10-19). Prereleases are rejected.

## Consequences

- The SDK version is an exact pin, not a range.
- Native folders (`ios/`, `android/`) are generated by Continuous Native Generation and never hand-edited.
- Upgrades happen once per SDK release, through `npx expo install --fix` and the full test suite.
- Verification of this choice is limited to the npm registry metadata read on the decision date. Expo's own compatibility notes for the chosen version are not yet checked and are recorded as a follow-up in `PROGRESS.md`.
