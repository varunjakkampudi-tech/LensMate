# Device measurements

Measure only on the target glasses and paired phone. Keep a small evidence record for the feature under evaluation; a
simulator result is software evidence and must never be reported as a device measurement.

For glasses photo transfer, record the glasses and phone models, camera configuration, scene and lighting, original image
dimensions and file size, transfer duration, integrity result, encrypted-storage result, failures, and test date. Preserve
the original capture for image-quality review when the owner explicitly wants to retain it; otherwise delete the test
media after recording the result.

For video, also record the configured resolution and frame rate, duration, dropped frames, file size, transfer completion,
and playback result. Do not advertise a quality or latency target until the chosen hardware meets it repeatedly under
documented conditions.

The [evidence template](evidence-template.csv) is optional. Keep validation evidence with the feature; a separate
progress score or status tracker is not needed.
