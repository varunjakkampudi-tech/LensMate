### Owner exception — direct work on main
This is a new repository with nothing deployed. The agent may commit and push directly to main, provided that:
1. Each commit is small, single-purpose and passes the full definition of done before it is pushed; CI is checked after each push.
2. A failing commit is fixed immediately or reverted with git revert. Never force-push or rewrite history.
3. Independent review in a fresh session before pushing changes to the provider broker, authentication, pairing, permissions or firmware update code.
4. The agent never flashes physical hardware, buys anything, uses real provider keys or makes paid API calls without the approved spend cap, and never changes GitHub settings.

### Public repository rules (until the owner makes it private)
Nothing is ever committed that should not be public, because history stays public even after the repository becomes private:
- no API keys, .env files, certificates or tokens
- no recordings, photos or video of the owner, the owner's home or any other person; test samples stay outside the repository
- no personal details (address, phone, location data)
- no proprietary hardware design files (custom PCB, enclosure); generic firmware and app code are fine
- no repository names or links in documents or commit messages
